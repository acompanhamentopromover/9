1. A Anatomia da Função

A Parábola e seus Limites

A função quadrática é definida por f(x) = ax2 + bx + c. O gráfico gerado é uma parábola que possui um ponto de retorno chamado Vértice (V).

a > 0 (Concavidade para Cima): A função admite um Ponto de Mínimo. É como o fundo de um vale.

a < 0 (Concavidade para Baixo): A função admite um Ponto de Máximo. É como o pico de uma montanha.
2. As Fórmulas do Vértice

Coordenadas V(Xv, Yv)

Não há segredo. Para encontrar o extremo absoluto, aplicamos as fórmulas base:

Xv = -b2a   |   Yv = -Δ4a

Lembrando que Δ = b2 - 4ac

3. A Dica de Ouro

Quando usar Xv ou Yv?

A maior causa de erros não é algébrica, é de interpretação. Analise estritamente a variável requisitada:

Fórmula Na Prática (O que é?) Palavras-chave
Xv O Fator Gerador. O instante temporal ou a quantidade exigida para que o máximo/mínimo ocorra. "Qual a quantidade...", "Em qual instante...", "Número de peças para obter..."
Yv O Resultado Final. O valor extremo alcançado propriamente dito. "Qual o lucro máximo?", "Qual a altura máxima?", "Qual o custo mínimo?"
4. Exemplo Ilustrado

O Lançamento da Bola

Considere o lançamento de um objeto com altura modelada por h(t) = 20t - 5t2 (a=-5, b=20, c=0).

Situação 1: "Qual o tempo para atingir a altura máxima?"
Resposta: Exige-se o fator gerador temporal (Xv).
Aplicando a fórmula: -b2a = -20-10 = 2 segundos.

Situação 2: "Qual é a altura máxima?"
Resposta: Exige-se o resultado absoluto final (Yv).
Aplicando a fórmula: -Δ4a = -400-20 = 20 metros.
